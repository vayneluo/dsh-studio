# DS Studio 落地页设计说明

## 目标

为 DS Studio 0.1.2 提供一页式中文产品官网，清晰说明产品用途、核心优势和运行要求，并让访客能直接下载 Windows x64 安装包。页面最终以纯静态文件部署到 1Panel，不影响现有 Tauri 应用的 `ui/` 目录。

## 交付边界

- 新网站位于 `landing/`，拥有独立的构建配置和依赖。
- 构建产物位于 `landing/dist/`，可直接作为 1Panel 静态网站目录。
- 不引入后端、登录、表单、统计脚本或远程运行时依赖。
- 产品版本统一展示为 `0.1.2`。
- 主下载链接固定为 `https://github.com/vayneluo/dsh-studio/releases/download/v0.1.2/dsh-studio_0.1.2_x64-setup.exe`，辅助链接指向 GitHub 仓库和 v0.1.2 Release 页面。

## 视觉方向

采用“深海工作台”风格：深蓝黑背景、蓝青品牌高光、细网格和充足留白。视觉应专业、克制、有桌面开发工具的力量感，不使用大面积紫色渐变、模板化卡片墙或喧闹装饰。

现有 `ui/logo.png` 与 `ui/brand.png` 作为品牌来源，复制到网站自身的静态资源目录，避免部署时跨目录依赖。界面预览使用 HTML/CSS 构造一个可信的 DS Studio 窗口，展示模型服务引导和工作台结构，不伪装成真实截图。

## 页面结构

1. 顶部导航：品牌、功能锚点、GitHub、下载按钮。
2. 首屏：产品定位“DeepSeek Harness，开箱即用的 Windows 桌面工作台”、简短说明、Windows 下载主按钮、版本与平台信息，以及桌面窗口预览。
3. 核心价值：免装 Node、官方 Web UI 桌面封装、离线预装插件、本地安全运行。
4. 模型服务：展示 DeepSeek、百炼、火山方舟、智谱、OpenAI、Anthropic、Gemini、OpenRouter、Ollama 和 OpenAI Compatible。
5. 使用路径：下载、安装、选择模型服务三个步骤。
6. 底部 CTA：重复下载入口、Release 说明链接、MIT 与上游许可说明。

## 交互与响应式

- 页面采用原生锚点导航和轻量 CSS/JavaScript 进入动画。
- 下载按钮在点击后直接触发浏览器下载，不进行中间跳转或平台探测。
- 桌面端首屏为左右不对称布局；窄屏改为纵向，按钮占据易触控宽度。
- 支持键盘导航、清晰焦点样式、语义化结构和 `prefers-reduced-motion`。
- 远程字体加载失败时使用本地中文字体栈，不影响内容与布局。

## 内容依据

页面卖点严格来自仓库 README：Tauri 管理窗口与进程、内置 Node.js 和 `@deepseek-ai/dsh`、首次模型服务引导、固定离线插件、本地回环地址、凭据通过 Harness API 管理、退出时终止 sidecar 进程树。不会宣称 README 未说明的性能、兼容性或安全认证。

## 验证

- 运行生产构建并确认生成 `landing/dist/`。
- 检查页面中不存在 `TODO`、占位链接或 0.1.1 等旧版本文案。
- 验证下载地址能跳转到 v0.1.2 安装包。
- 检查主要桌面与移动断点、键盘焦点和减少动态效果规则。
